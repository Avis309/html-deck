Drop .html file to open

File changed on disk

Someone (or another script) modified this file after you opened it. Overwriting will lose those changes — a backup is kept in .htmldeck_bak.

This save rewrites the whole file

Your edits could not be patched in place, so the whole file will be rewritten. Content stays the same, but line breaks, quotes… outside your edits may change. Files opened through the server keep a backup of the old version.
