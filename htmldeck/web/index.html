Mở một tài liệu HTML

Chọn file trong workspace, mở từ máy tính, hoặc kéo-thả file vào đây.

Ghi chú
Thả file .html để mở

File đã thay đổi trên đĩa

Có ai đó (hoặc một script khác) đã sửa file này sau khi bạn mở. Lưu đè sẽ làm mất thay đổi đó — bản cũ vẫn được sao lưu trong thư mục .htmldeck_bak.

Lần lưu này sẽ ghi lại cả file

Không vá riêng được vùng vừa sửa, nên file sẽ được ghi lại toàn bộ. Nội dung giữ nguyên, nhưng cách xuống dòng, dấu nháy… ở những chỗ bạn không sửa có thể bị đổi. File mở qua server vẫn có bản sao lưu cũ.
